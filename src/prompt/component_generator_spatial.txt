<HARD_GRAMMAR_CONSTRAINTS>
1. The Centerline Rule: 
   Roads and Lanes have a `centerline`. Intersections DO NOT. 
   - CORRECT: `pt = new OrientedPoint in road.centerline`
   
2. The Neighbor Finder Rule: 
   To find left/right neighbors, drill down to the `LaneSection` level. Do not use Lane objects.

3. The "New" Rule: 
   Always use the `new` keyword when defining an OrientedPoint.
   - WRONG: `OP = OrientedPoint on ego_lane.centerline`
   - CORRECT: `OP = new OrientedPoint on ego_lane.centerline`

4. Random Boolean Comparison Rule: 
   Control flow MUST NOT depend on comparisons involving random boolean values or properties of random objects.

   - CORRECT: Select randomly first, then use `require` at the bottom of the script, OR filter deterministic lists before randomizing.

5. Single Property Priority: 
   The `position` property can only be specified once with the same priority. Do not chain conflicting positional specifiers.
   - WRONG: `pedSpawnPt = new OrientedPoint right of (ahead of egoSpawnPt by 25) by 5`
   - CORRECT: `IntPt = new OrientedPoint following egoInitLane.orientation from egoSpawnPt for 25`; `pedSpawnPt = new OrientedPoint right of IntPt by 5`

6. Facing Specifier Usage: 
   `Lane.orientation` is a VectorField and cannot be used directly in the `facing` specifier.
   - WRONG: `advSpawnPt = new OrientedPoint at advInitLane.centerline.end, facing advInitLane.orientation`
   - CORRECT: `advSpawnPt = new OrientedPoint on advInitLane.centerline`

7. Finding Intersections: 
   Find them in `network.intersections`. Do not check `isIntersection` on Road/Lane objects.
   - CORRECT: `intersection = Uniform(*filter(lambda i: i.is4Way, network.intersections))`

8. Trajectory Definition: 
   Defined as a list of lanes/lane sections.
   - CORRECT: `egoTrajectory = [egoInitLane, egoManeuver.connectingLane, egoManeuver.endLane]`

9. Random Control Flow Rule (CRITICAL): 
   NEVER use Python `if`, `for` loops, list comprehensions `[x for x in ...]`, `filter()`, or `len()` whose condition depends on a variable created by `Uniform(...)`.
   - WRONG: `[m for m in advManeuver.conflictingManeuvers]` (where advManeuver is random)

10. Invalid "offset by" Usage (CRITICAL): 
    `offset by` requires a `<vector>`. You CANNOT offset a `Region` or `centerline` by a scalar (float or Range).

    - CORRECT: `new OrientedPoint on lane.centerline` (Let requirements handle distance)

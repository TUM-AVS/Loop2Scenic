7. Random Variable "None" Checks (Compile-time vs. Sample-time)
Never use standard Python if statements or is None checks on objects generated by Uniform() or other random distributions. Because random variables are unresolved objects at compile-time, a check like if random_var is None: will always evaluate to False, bypassing fallback logic and causing NoneType attribute errors during generation. Always filter and group deterministic valid pairs into lists before applying Uniform().

8. Premature Termination & Intersection Behaviors
In Scenic, a simulation terminates immediately when the ego vehicle's behavior completes. If an actor is meant to cross or navigate an intersection, it MUST be assigned a FollowTrajectoryBehavior and passed a valid trajectory. If it is only assigned a FollowLaneBehavior, the behavior (and the simulation) will terminate prematurely the moment the vehicle reaches the end of its starting lane. Always verify that if a trajectory is defined in the script, it is actually passed into the actor's behavior.
